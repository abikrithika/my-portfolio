# Reflection

## Part A – Improvements Implemented

1. Added global box-sizing to improve layout consistency and prevent unexpected sizing issues.

2. Added rel="noopener noreferrer" to all external links to prevent tabnabbing security vulnerabilities.

3. Wrapped main content inside <main> for better semantic structure and accessibility.

4. Moved inline JavaScript to an external script.js file to improve separation of concerns.

5. Added a skip-to-main-content accessibility link and improved its UI positioning.

## Key Learnings

1. I learned how small security practices like using rel="noopener noreferrer" can prevent real-world vulnerabilities.

2. I understood the importance of semantic HTML elements like <main> for accessibility and screen reader support.

3. I learned why separating JavaScript from HTML improves maintainability and follows best development practices.

4. I learned how implementing accessibility features, such as a skip-to-main-content link, improves usability for keyboard and screen reader users.

## Part B – Ethics and Risks of AI in Development

### 1. Over-Reliance on AI

AI tools can make developers dependent and reduce critical thinking skills.
Mitigation: I will always review and understand AI-generated code before using it. I mainly use AI for self-paced learning by asking questions such as what, why, where, and how, focusing on understanding concepts and implementation steps rather than receiving full solutions.

### 2. Security Risks

AI may generate insecure or outdated code.
Mitigation: I will test and review AI-generated code carefully before deploying it.

### 3. Intellectual Property Concerns

AI-generated code may unintentionally resemble copyrighted work.
Mitigation: I will treat AI output as a learning aid and ensure I understand and modify the code appropriately.
